[HP2236BVA-31] Fix LAN IP display wrong in Home page
Feedback
Project: airoha/2025q3 | Owner: [Marusys VINA] Tien
Detailed Feedback ### Potential Issues 1. **Logic Error in `FalMesh_updateLanInfo` (AP Mode):** The loop to find the controller IP returns immediately after finding the first match (`return;`). If there are multiple ports to update, it might miss some. However, since it's looking for the controller's own IP in AP mode, there might only be one relevant port, but the logic should be verified. 2. **Resource Management:** In `getEthSlaves`, if `topoJsonObj` creation fails, `topoBuffer` is deleted, which is correct. However, ensure `TreeMapObject` doesn't have other side effects if it fails mid-constructor (though here it's just a buffer wrapper). 3. **Port Indexing:** `portIndex = atoi(pDevList.devList[i].path) - 1;` assumes `path` is a numeric string representing a 1-based port index. If `path` is not numeric or has a different format, `atoi` will return 0, resulting in `portIndex = -1`. There is a check for `portIndex < 0`, but the source of `path` should be confirmed. 4. **String Safety:** `snprintf` is used correctly with sizes, which is good. ### Suggestions - Add more logging around the `isMacInList` and `portIndex` logic to help debug if the IP still doesn't display correctly in some edge cases. - Consider if `HalGateway_getConnectedDevicesList` could return stale data and if a refresh is needed.
