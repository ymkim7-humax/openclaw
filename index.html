[HP2236BVA-37] Fix SSH/Telnet access issue when enabled via CWMP
Detailed Feedback
Project: airoha/2025q3 | Owner: [Marusys VINA] Dante
### Detailed Feedback
Click to expand There are two main issues with this patch: 1. **Incomplete Deletion Logic**: The `else` block (used when `enabled` is false) only deletes the rule for port 22. If `service_type` is `SERVICE_TELNET`, it will fail to remove the port 23 rule, leaving the service exposed. 2. **Hardcoded Rule Management**: Using `iptables -I INPUT 1` ensures the rule is at the top, but the deletion logic uses `-D` without specifying the index. If multiple rules exist, this might not behave as expected. **Suggestion**: Update the `else` block to check the `service_type` and delete the corresponding port rule (22 or 23).
