[ARHT-333] Implement R_CPE7 Diagnostics - HTTP
DETAILED FEEDBACK
Project: airoha/2025q3 | Owner: [Marusys VINA] Ray
### HTTP Diagnostics Implementation Analysis

**Observations:**
- `FalUtil_string_validate` 도입으로 사용자 입력값(URL) 검증 로직 강화.
- `wa_build_rcpe7_device_payload` 분리로 코드 가독성 향상.

**Concerns:**
1. **Security (Command Injection):** `system(cmd)`를 사용하여 `curl`을 호심합니다. 검증 로직이 있더라도 `execl` 또는 `POSIX spawn` 계열 함수를 사용하여 shell 메타 문자 해석 위험을 원쳌 차단하는 것을 권장합니다.
2. **Parsing Logic:** `extracted_domain` 추출 시 `strstr`과 fix offset(`strlen("http://")`)을 사용하는데, `HTTP://`(대문자) 나 Port 번호가 포함된 경우 오동작 가능성이 있습니다.
3. **Memory:** `TreeMapObject` 포인터 처리 시 `root->set` 방식으로 변경되었는데, stack 변수인 `payload`의 lifecycle을 다시 확인해야 합니다.
[ARHT-182] Adjust boot sequence
DETAILED FEEDBACK
Project: airoha/2025q3 | Owner: Yeongman Kim(김영만)
### Boot Sequence Reordering Analysis

**Pros:**
- LAN/PON 우선 시작을 통해 네트워크 연결 성립 셍션을 앞당김.
- `dnsmasq` 최적화(`noping`, `force`) 및 `BOOT` 플러그 제거로 DHCP 서비스 응답 셍션 단쵕.

**Risks & Suggestions:**
1. **Dropbear/uhttpd (START=99):** 맨 마지막으로 밀려났습니다. 만약 부팅 중간에 서비스 프로세스가 항(Hang) 되면 Telnet/SSH 접쇍이 안 되어 디버깅이 힘들 수 있습니다. 테스트 버전에서는 조금 당기는 것을 게토.
2. **wait_lanup (START=23):** `ubus call`을 loop로 돌리는데, 최대 타임아웃 설정이 없어 네트워크 츹셋 초기화 실패 시 부팅 시퀀스 전체가 멈출 수 있습니다.
