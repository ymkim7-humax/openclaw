[HP2236BVA-134] Update ONT software version.

Project: airoha/2025q3 | Owner: [Marusys VINA] Karina
### detailed feedback
Click to expand - **Potential Command Injection Risk**: The function `update_xpon_sw_version` uses `snprintf` to build a command string and then executes it using `system(cmd)`. While `buffer` is populated via `omci_lib_uci_get`, if that UCI option is ever user-controlled or contains shell metacharacters, it could lead to command injection. - **Redundancy**: Use of `system("uci set ...")` is generally less efficient than using UCI library APIs directly if they are available in the same context. - **Error Handling**: `system()` calls do not check return values.
