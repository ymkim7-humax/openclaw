[ARHT-108] Dual uplink: Add Connection Type (GPON line)
DETAILED FEEDBACK
Project: airoha/2025q3 | Owner: [Marusys VINA] Jack
The patch introduces HalNetwork_getVendorList and uses it in NetworkUplinkGet, but the prototype for this function is missing from hal_network.h. Additionally, the vendor list is hardcoded to a count of 3 with static names ("Connection 1", etc.) in the API layer, which might be better served by a more dynamic approach or at least defined constants. There is also a pre-existing typo HalUltils_getPIDByName in the context of hal_network.c.



Detailed Feedback

- **Missing Prototype**: `HalNetwork_getVendorList` is used in `FalNetwork.cpp` but not declared in `hal_network.h`.
- **Hardcoded Strings**: "Connection 1", "Connection 2", and "Connection 3" are hardcoded in the API response. These should ideally come from the HAL or be defined as macros.
- **Consistency**: The `vendorId` is added to `HalNetwork_dualuplink_t` but ensure all initialization paths for this struct are covered.
