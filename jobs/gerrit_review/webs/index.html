[ARHT-210] P_CPE10 support SUB's client information
DETAILED FEEDBACK
Project: airoha/2025q3 | Owner: [Marusys VINA] Steven

Detailed Feedback on wa_publish_api.cpp

### Potential issue in `wa_fill_bandmode` logic

The use of `strstr` to detect WiFi modes might lead to false positives. For example:
```cpp
if (strstr(bandMode, "b")) {
    bandmodes.addArrayItem("802.11b");
}
```
If `bandMode` is `"be"` (802.11be/WiFi 7), `strstr(bandMode, "b")` will return true, incorrectly adding `802.11b` to the supported modes. 

Consider using more specific checks or ensuring `bandMode` doesn't contain ambiguous substrings.

### Type consistency
The patch changes many `unsigned int` usages to `int` when calling `pWifiDevicesInfo->set(...)`. While this matches the library's expectation, ensure that values like packet counts (which can be very large) won't overflow if treated as signed 32-bit integers in downstream consumers.

### Interface path mapping
`wa_updateEthernetIfToPath` depends on `ethernetMap`. Ensure this map is correctly populated for all supported hardware revisions.
