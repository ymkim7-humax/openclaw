# HP2236B 코드 분석 작업 계획서 (Ollama 병렬 분석 체계)

## 1. 개요
Ollama 로컬 모델을 활용하여 HP2236B 프로젝트의 전체 소스 코드, 환경 설정, 빌드 시스템을 전수 조사하고 지식 베이스를 구축함.

## 2. 작업 공간 분리 및 환경
- **작업명 (JOB):** `hp2236b_analysis`
- **호스트 경로:** `~/.openclaw/jobs/hp2236b_analysis/`
- **워크스페이스:** `~/.openclaw/workspace/jobs/hp2236b_analysis/`
- **분석 대상 디렉토리 (Docker 내부):**
    - `.../build_dir/target-aarch64_cortex-a53_musl/`: 컴파일된 개체 및 바이너리 분석용.
    - `.../root-airoha/`: 실제 배포되는 RootFS 기반 소스/설정 추적.
    - `linux`, `boot-loader`: 커널 및 부트로더 하위 모듈 전수 조사.

## 3. 단계별 실행 계획
### Phase 1: 기반 구축 (오늘자 코드 고정)
1. **분석용 빌드 실행:** `jobs/hp2236b_analysis/build.sh`를 통해 `build_dir` 내 결과물 생성.
2. **정적 분석 에이전트 가동:** Ollama(로컬 모델) 서브 에이전트들을 활용하여 파일별 역할 파악 및 메타데이터 생성.
3. **상호 참조 맵 작성:** 소스코드(`src`), 환경파일(`.conf`, `.uci`), Makefile 간의 연결 고리 분석.

### Phase 2: 변동분 추적 (Incremental Analysis)
1. **Git Log 분석:** 1차 분석 완료 후, 최근 커밋 히스토리를 바탕으로 변경된 로직과 의도 파악.
2. **Gerrit 연동:** 현재 대기 중인 7~10건의 Gerrit 패치가 전체 시스템 아키텍처에 미치는 영향 분석.

### Phase 3: 지능형 리뷰 엔진 가동
- 새로운 패치가 올라올 때마다 "전수 조사된 지식"을 바탕으로 부작용(Side-effect) 및 보안 취약점을 사전 감지.

## 4. 기대 효과
- **병렬 처리:** Gemini API 제한 없이 수십 개의 파일을 동시 분석.
- **정확도 향상:** RootFS에 포함되는 실제 파일들만 집중 분석하여 실무 정합성 확보.
- **커리어 서포트:** 매니저님의 수동 노트를 대체할 수 있는 강력한 기술 백과사전 자동 구축.
